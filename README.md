# CSA-Monitor (Web-App)

Startseite, Monitor für die Belastungsübung der CSA-Träger und Übungsanwesenheit der TE Gefahrstoffzug Miehlen.
Die Seite enthält nur Programmcode. Die Daten liest sie nach Anmeldung bei Dropbox auf dem Gerät und entschlüsselt sie dort; Anwesenheitsmeldungen schreibt sie verschlüsselt in ihren eigenen App-Ordner.
