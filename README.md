# Gefahrstoffzug TE Miehlen (Web-App)

Einsatz (Stoffsuche über GESTIS, Beständigkeitslisten, Einsatz-Unterlagen) und Übungen (CSA-Monitor, Übungsanwesenheit) der TE Gefahrstoffzug Miehlen.
Die Seite enthält nur Programmcode. Daten und Unterlagen liest sie nach Anmeldung bei Dropbox aus ihrem eigenen App-Ordner auf das Gerät; die Personaltabelle wird nur dort entschlüsselt.
